# 🖥️ SysPulse: Self-service Business Intelligence (BI) and data visualization
Designed for business users, analysts, and decision-makers, it enables teams to transform raw data into interactive, meaningful visual insights without requiring advanced technical expertise.
Users can quickly evaluate the platform by downloading the Windows executable (EXE) demo app, which includes preloaded sample datasets and supports immediate CSV and JSON file imports.

# 🚀 Key Project Capabilities
## Interactive Dashboards: 
Create, customize, and manage comprehensive dashboards tailored to your business metrics.
## Dynamic Widget & Report Creation: 
Build individual visual widgets and compile them into structured, presentable reports.
## On-the-Fly Dashboard Additions: 
Pin new widgets and charts directly to existing dashboards for real-time tracking.
## Self-Service Analytics: 
Explore data fluidly with intuitive filtering and interactive reporting capabilities.

# 🛠️ Technical Architecture
## Frontend: 
React.js for building a highly responsive, modern user interface.
## Backend: 
Node.js to power efficient data processing and seamless application logic.
## Database: 
SQLite for lightweight, fast, and serverless local data storage.
## Data Visualization: 
Apache ECharts to render rich, interactive, and high-performance charts and graphs.
